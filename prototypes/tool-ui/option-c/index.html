Equations and substituted values

Calculation chain
Equation (1): As = π/4 (d − 0.9382p)² = 57.99 mm²

As: tensile stress area; d: nominal diameter; p: thread pitch.

Equation (2): Fp = SpAs = 37.11 kN

Fp: proof load; Sp: proof strength.

Equation (3): Fi = αFp = 27.83 kN

Fi: target preload; α: proof-load fraction.

Equation (4): T = KdFi = 41.8 N·m

T: tightening torque; K: nut factor.

Show intermediate steps
  1. Resolve d and p from the selected thread.
  2. Calculate stress area and proof load.
  3. Apply α to set preload.
  4. Apply K to estimate torque.

Background and limits

Open engineering context

This is an early sizing model, not a joint verification. It does not calculate stiffness, service-load sharing, embedding, fatigue, thread stripping, or tightening scatter.
