3.0 Calculation notes

Equation (1): As = π/4 (d − 0.9382p)²
Equation (2): Fp = SpAs
Equation (3): Fi = αFp
Equation (4): T = KdFi
  1. Calculate tensile stress area from nominal diameter d and pitch p.
  2. Multiply area by proof strength Sp to obtain proof load.
  3. Apply the selected preload fraction α.
  4. Apply the nut-factor torque relationship.

4.0 Background

Open background and limitations

This four-equation model is useful for an early torque estimate. It omits joint stiffness, external service load, embedding loss, thread stripping, fatigue, and tightening scatter.
