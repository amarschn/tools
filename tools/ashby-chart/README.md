# Ashby Chart Material Selector

This address redirects to [Materials Explorer](../materials-explorer/), the
site's single Ashby chart tool. It uses the curated Materials database and
preserves the sources, conditions, named states, intervals, and specified
bounds attached to each plotted value.

The Netlify redirect is permanent. The small HTML fallback keeps the old
address usable on GitHub Pages and local static servers. The tool is no longer
a separate catalog entry.

The historical seven-material Python helper in `pycalcs/materials.py` remains
for API compatibility. It does not supply the public chart.
