Machine Timing

Real cam machines (packaging, assembly, presses) run several followers off one shaft. Lay out each station's moves on a shared timing diagram, write down which positions must never overlap, and the tool flags collisions in degrees and milliseconds. Drag the round handles to move a stroke; drag the square handles to change where and how far it ends.
