# Materials data used by tools

`selection.json` is generated by `scripts/build_material_selection.py` from the
public Materials catalog. It supplies Materials Explorer with compatible
observation pairs, citations, and Python-computed performance indices. Do not
edit it. Add or correct observations under `materials-lookup/curated/`, rebuild
the Materials release, then regenerate the projection. The normal site build
also regenerates this file.

The chart and Materials lookup share the same authoring records. The projection
is stored here because it is derived reference data for material selection,
with an explicit build ID and catalog hash connecting it to the lookup release.

`materials.json`, review files, and `staging/` belong to the older 60-material
selection/ingestion workflow. They remain for historical studies and existing
`pycalcs.material_db` callers. The public chart no longer reads them. Migrating
those APIs is a separate task; new chart data belongs in the curated Materials
project.
