# Ashby Chart Interface Prototypes

Date: 2026-10-31

Five working studies for the next version of the Ashby chart. They use real database
values and no chart library. Nothing here is linked from the public site, and
`netlify.toml` returns 404 for `/_internal/`.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/_internal/prototypes/2026-10-31_ashby-chart-ui/`.

## Studies

| Study | Question it tests |
| --- | --- |
| [A, Selection stack](a-stack/) | Should narrowing work like Granta, with an ordered chain of stages? |
| [B, Studio](b-studio/) | Should the chart fill the screen, with axes, tags and selection on the chart itself? |
| [C, More axes](c-axes/) | Which way of adding a third or fourth axis is readable: 3D, colour and size, parallel axes, or a matrix? |
| [D, Blob lab](d-blobs/) | Which shape looks right? Four methods drawn from the same data. |
| [E, Design brief](e-brief/) | Should people be able to start from the part and let the chart follow? |

Tags are stored in the browser and shared by all five studies. Clear them by deleting
each tag in study B.

## Files

- `core.js`: data loading, the formula parser, filter stages, tags, blob geometry and the canvas chart.
- `shared.css`: colour tokens for light and dark themes, and shared components.
- `data.json`: generated by `build_data.py` from `data/materials/selection.json`. Rerun it after a data change.

## Limits of these studies

**Values are simplified.** Each material has one value per property: the median of its
room-temperature observations. Production pairs observations by compatible conditions,
so a real build must keep that rule. Do not take design values from these pages.

**Formula axes need a decision on units.** Formulas use display units (GPa, kg/m³),
which makes `E^0.5/rho` easy to type but gives a number with no labeled unit.

**Blobs are a drawing choice.** Every shape here is a visual grouping of plotted values.
None of them is a statistical confidence region or the true range of a family. Very
soft settings draw regions where no material was measured.

**Some sizes are not tested.** Layouts were checked at 1400 and 390 px wide in Chromium.
Touch gestures such as pinch zoom are written but were not tested on a real device.

## Measured against the current chart

Chromium, same machine, local server with no network delay, median of three page loads
and nine toggles. A deployed page also has to download its data and Plotly.

| | Current chart | Study B |
| --- | ---: | ---: |
| Page ready | 538 ms | 69 ms |
| Toggle a family, to next frame | 84 ms | 19 ms |
| Chart data, gzip | 1,486 KB | 83 KB |
| Chart library | Plotly 2.27 | None |

The data figures are not a like-for-like saving. `selection.json` carries every
observation, its conditions and citations, and precomputed chart pairs. A production
version could keep the small file for the first paint and fetch citations when someone
opens a material.
